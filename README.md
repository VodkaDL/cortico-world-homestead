# 田园烟火 · cortico-world-homestead

给 Coopanion 桌宠的一方小院：开荒种田，照顾饮食起居，把收成做成饭菜，再背上货物去赶集。

参考 [AqualCross/cortico-world-eat](https://github.com/AqualCross/cortico-world-eat) 的 **World API 6** 接口、纯构造工厂、生命周期、工具与 WebUI 分层、串行操作及原子存档方式，重新实现扩展领域逻辑。零运行时 npm 依赖，中文界面；许可与来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 已实现

- 六块初始荒田；开垦、播种、浇水、除草、施肥、防虫、排水、稻草人、清田和收获。
- **30类作物、94道内置菜谱**。水稻、小麦、玉米、豆类、根茎、叶菜、瓜果等按现实生长天数缩短到约28–120个真实小时；缺水、杂草、虫害和健康会影响生长与产量。支持主人添加新收获物，再为种子定义新作物。
- 晴天、及时雨、热浪干旱、暴雨洪涝、蝗灾、和煦日照、蜜蜂授粉、倒春寒和冰雹；按持久种子与真实时间段产生，刷新页面不会反复抽天气。
- 蒸、炒、煮、炸、烤、凉拌；厨具占用，材料和调料实扣，水与燃料消耗，真实时间等待出锅。稻谷、小麦可用手摇磨制米、磨粉。
- 批次保鲜、不同储藏衰减倍率、容器容量与厨房成品空间预留；移动、买卖、交换、烹饪、加工均保留已有陈旧程度。
- 饱腹、愉悦、健康、体力、水分、清洁、社交和保暖八项数值相互作用。好吃的新鲜食物增加愉悦；饥饿、缺水、疲劳、雨中玩耍感冒影响健康；支持喝水、洗漱、休息、玩耍、服药。
- **每日真实时间06:30–11:30、14:00–17:00**营业的集市，默认 Asia/Shanghai。金币和货物有重量；健康影响负重上限，负重影响路程。可以抵达时已闭市，也可以闭市返家。
- 油坊、盐坊、茶坊、器具坊、作物坊、食材铺；马车载重默认180kg的流动商人每日随机刷新有限库存。买卖、金币补差价的物物交换，买到菜谱后才解锁。
- 布告栏：支付2金币或足值背包物件，次日优先携带世界已有的需求物品。超过载重时先各带一件、按重量升序，最大化满足的种类数；多余抵价不找零。
- 主人专属菜谱编辑器、物品编辑器，服务器校验重复名称/ID、属性边界、作坊相关性、食材可用性、免加热生食限制及成品重量。
- 关闭应用后仍按真实时间结算；精确记录出锅、抵达、起床时刻，支持重启后补算。坏存档保留原件并报错，成功保存前不提交动作。

## 安装到本机 Coopanion

支持当前本机版本 **Coopanion 0.2.23 / World API 6**。扩展使用 Node 18.17+ 可执行的原生 ESM；宿主框架检查脚本需 Node 22.15+，建议直接使用应用自带的 Node 24。

推荐：设置 → 扩展 → 安装本地扩展，选择本包目录。重启 Coopanion 后，在 World 页启用 **田园烟火**。

本机安装脚本（不会更改旧「吃饭」World 和它的存档）：

```powershell
node tools/install.mjs "I:\Coopanion"
```

脚本将发布所需文件复制到：

```text
I:\Coopanion\data\extensions\local\cortico-world-homestead
```

并创建 `node_modules/cortico-world-homestead` 的目录联接、登记 `link:` 依赖；已有不同位置的同名扩展会报错而不覆盖。扩展清单改动前会备份。**重启并在 World 页启用**后才加载，不会强制退出正在运行的桌宠。

新存档位置：

```text
I:\Coopanion\data\home\companion\data\homestead\state.json
```

八项人物数值属于本 World；旧「吃饭」里的饱食度仍是另一份状态。可以在 World 页按需要停用旧「吃饭」，避免桌宠同时经营两份饮食系统。

## 主人页面

| 页面 | 功能 |
| --- | --- |
| 田园总览 | 八项人物数值、照料动作、天气和事件记录 |
| 田地与天气 | 六块田的开荒、播种、照料、灾害处理和收割 |
| 厨房与菜谱 | 灶台任务、磨谷、已学/全部菜谱、烹饪与进食 |
| 仓储与保鲜 | 容量、各批次新鲜度、移动/卸货、厨余处理和堆肥 |
| 赶集与公告 | 选择携带物与金币、出发/返程、作坊/商人买卖、物物交换、需求公告 |
| 添加菜谱 | 逐行食材和佐料、方式、分钟、加水、产量、价格、保鲜、饱腹、愉悦和步骤 |
| 添加物品 | 唯一物品、分类、重量、价格、保鲜、食用属性、标签和作坊；种子配套生长模型 |

新增菜谱和物品在**配置时区的第二个自然日**生效，跨午夜即是次日，不是添加后满24小时。固定作坊商品必定次日上架；流动商人商品次日起有机会随机出现，可以随后到公告栏订货。

新增菜谱**不会立即教给桌宠**。桌宠的 `homestead_status area=recipes` 只显示已掌握菜谱，宠物工具没有新增物品/菜谱的入口；主人能在管理页查看全目录。

所有数量按目录中一个销售单位计：主料大多100g，姜蒜葱10g，盐2g，油10g，茶叶3g，鸡蛋60g。前端会显示每种材料实际克重，避免把份数当成克数。

## 时间、保鲜与经济

详见 [数值与规则](docs/DESIGN.md)，全量作物/物品/菜谱见 [目录参考](docs/CATALOG.md)。价格是参考常见生活物品相对价格设计的游戏平衡参数，不是实时市场价格；金币为游戏代币，**每枚0.5g，允许小数至0.01金币**，不按真实金价兑换。

| 容器 | 容量 | 示例老化倍率（越小越慢） |
| --- | --- | --- |
| 食品柜 | 20kg | 1.00 |
| 粮仓 | 80kg | 干谷物/干豆/面粉/面条0.20，种子0.30；其他湿鲜食材1.30 |
| 地窖 | 40kg | 根茎0.35、其他果蔬0.65、熟食0.80 |
| 冰箱 | 25kg | 熟食0.04、肉奶0.03、鸡蛋0.10、豆腐0.08、果蔬0.30 |
| 工具棚 | 60kg | 仅非食品工具和材料 |
| 背包 | 健康时12kg | 基准1.20；健康下降会降低可承担负重 |
| 厨余垃圾桶 | 10kg | 过期食物先入桶，再清空或按每满1kg制一份有机肥 |

例：常温基准4小时的熟饭，初始放冰箱约100小时完全变质；先在外面放2小时，再放冰箱，只剩约50小时。新鲜度不足35%时吃下会降低健康与愉悦；达到保质期则完全不可食用。烹饪拒收腐败超过80%的原料，并将最差原料的腐败比例传给成品。

## 当前边界

- 这是玩法模拟，不能把保鲜时长与菜谱步骤当成现实食品安全或医疗建议。未模拟微生物种类、冰箱停电、真实地图/交通、季节播期和物品体积。
- 不会自动售卖、自动做饭或自动安排赶集；主人或桌宠通过已有工具做决定。停用期间不执行动作，重新启用后结算时间。
- 背包货物回家后不会自动挤进冰箱；保留在背包继续较快老化，请及时卸货。路上健康下降可能使现有背包超过新的舒适负重，仍允许返程，新增货物会受新上限限制。
- 已有商品通过作坊、商人随机货池或公告次日订货购买；不模拟商人经营利润、收购物品的转售过程，售出物退出玩家库存。
- 自定义非厨具、特殊物品按其分类具有目录/食用/种植/交易能力；新工具名称不自动注入一段任意运行代码。内置厨具与加工机的功能固定。
- 老化按实际小时累计，天气/生长以15分钟边界和动作时刻分段积分；不同查看频率可能带来轻微积分误差，不改变真实时间、营业时间和保质期。
- 离线通知只向桌宠补最近8条，完整最近160条仍存档，页面显示最近50条，避免长时间离线后消息洪泛。
