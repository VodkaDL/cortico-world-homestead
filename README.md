# 田园烟火

给 Coopanion 桌宠的一方小院：开荒种田、养殖、做饭、赶集，也照料自己的日常。扩展使用 World API 6，运行时不依赖第三方 npm 包。

**当前版本：1.0.1**。升级会保留原有田地、库存、金币、菜谱、动物与日记；不会重置世界存档。

## 主要玩法

- **农耕**：六块荒田需要先开垦。种植30类作物，浇水、除草、施肥、防虫、排水并应对旱涝、蝗灾、倒春寒等天气。作物按真实时间生长，条件影响产量。
- **养殖**：关闭宝宝模式后可养鸡、鸭、鹅、牛、羊、猪和鱼，照料繁育、收集蛋奶毛、治疗疾病并处理自然寿终。宝宝模式默认开启，可随时在 World 配置切换。
- **厨房**：100道内置菜谱，支持蒸、炒、煮、炸、烤和凉拌。食材、佐料、水、燃料、厨具与烹饪时间均会检查；主人可添加菜谱，但桌宠需在集市买到后才能学会。
- **储藏**：食品柜、粮仓、地窖、冰箱、工具棚、背包、厨余桶和门廊收货箱各有容量与保鲜效果。腐败会降低食物效果；完全变质的食物不能食用，只能处理为厨余。
- **生活状态**：追踪饱腹、愉悦、健康、体力、水分、清洁、社交和保暖。吃饭、休息、洗漱、玩耍与天气事件会改变这些数值。
- **主动照料**：默认开启。在家且未休息时，桌宠会按需求洗漱、寻找可食用库存或尝试制作已掌握的菜、低社交时室内玩耍；赶路期间不会行动。可在 World 配置关闭。
- **聊天社交**：主人通过桌宠气泡发来的消息会为社交值增加少量陪伴收益。系统只记一条陪聊经历，不存储或分析消息正文。
- **集市**：每日06:30–11:30、14:00–17:00开放（默认 `Asia/Shanghai`）。有固定作坊、随机流动商人、买卖、以物易物、布告栏订货、代宰和次日跑腿送货。货物、金币和随行牲畜都会影响负重与路程。
- **日记**：每晚当地时间21:00根据本世界实际经历写第一人称日记，提炼当天重点而非逐条复述通知；离线后会补写，不会重复日期。
- **主人管理**：前端提供菜谱和物品编辑器。新增菜谱不会直接解锁，新增物品次日起进入对应作坊或流动商人的货池。

## 安装与配置

在 Coopanion 的 World 页面启用「田园烟火」。首次进入可选择宝宝模式；养殖启用后，系统会提供初始动物、饲料、兽药和屠宰套件。桌宠的耕作、厨房、库存、养殖、赶集和照料操作均通过 World 工具与页面执行。

World 配置可调整营业时区、作物生长倍率、天气、饥饿速度、负重、商人载重、动物年龄倍率，以及「桌宠主动照料自己」开关。

食材保鲜与营养为游戏规则，不是食品安全或医疗建议。每枚金币重0.5g；物品重量以g或kg展示。

## 开发与验证

需要 Node.js 18.17 或更新版本：

```powershell
npm test
npm run describe
npm run check
npm run drymount
```

使用独立浏览器预览：

```powershell
npm run preview
```

源码主要位于 `src/`，浏览器面板在 `dist/webui.js`，工具与测试在 `tools/`、`test/`。玩法数值、接口和参考实现说明见 [`docs/DESIGN.md`](docs/DESIGN.md)、[`docs/IMPLEMENTATION.md`](docs/IMPLEMENTATION.md) 与 [`docs/FEATURES.md`](docs/FEATURES.md)。版本记录见 [`CHANGELOG.md`](CHANGELOG.md)。
