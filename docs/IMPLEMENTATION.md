# 田园烟火 · 实施记录

## 目标与顺序

1. 按 AqualCross/cortico-world-eat 的 World API 6 接口实现独立扩展：纯 create、start/stop 生命周期、工具、自定义 WebUI、串行队列与原子存档。
2. 实现共享纯领域引擎：荒田开垦、作物照料、天气、批次保鲜与储存、烹饪、人物数值、真实时间离线补算。
3. 实现固定作坊、有限库存商人、金币重量、负重行程、买卖/物物交换、次日公告与目录生效。
4. 主人管理页编辑配方与新物品；所有输入由服务器验证，宠物工具不提供管理权限。
5. 用假时钟验证跨日、闭市、重启、容量、腐败和交易；用本机框架 dry-mount 验证兼容性，再安装并提交 GitHub。

## 核心决策

- 世界时间与真实 UTC 毫秒同步；市场日历用 Asia/Shanghai（可配置 IANA 时区），营业时间 06:30–11:30、14:00–17:00，结束时刻闭市。
- 作物现实周期按每 30 个现实生长日折合 1 个游戏真实日；不快进市场、不快进食品保鲜。
- 物品按批次记录已消耗的常温保质时长；移动容器不会重置新鲜度。熟食保质期是游戏模型，不作为现实食品安全指南。
- 所有动作在同一队列中先推进时间、克隆交易状态、完整验证成功后提交；失败动作不扣物品和金币。
- 有限世界事件采用固定时间格与持久随机种子，刷新页面不增加天气触发概率；离线使用相同结算路径。
- 新菜谱次日起进入商人货池，必须赶集购得才解锁。新增物品不可重名，种类和作坊匹配由服务器检查。
- 游戏价格是参考常见零售价比例设计的固定平衡参数，不声称为实时商品或贵金属报价。

参考源码仅作架构参考，独立实现领域逻辑，保留来源及 MIT 许可说明。

## 1.1.0 增量实施

- 增加独立 `livestock.js`：七类动物、30倍生理年龄、受精和妊娠、产后泌乳、饲槽克重、疾病疗程、自然寿终与无害化处理。
- 扩展批次元数据，保留来源动物、屠宰等级、保鲜覆盖与饱腹系数，穿过转仓、烹饪和托运；屠宰产物使用基础目录，不覆盖世界商品定义。
- 以实际承运者分配货物；代宰后重新计算驮力。待运货物、跑腿订单、次日库存互相独立，日刷新不删除订单；08:00送达不依赖桌宠在家。
- 宝宝模式默认开启且首次弹窗选择。运行中切回宝宝模式冻结动物，保留市场活禽与肉类。礼包只发一次，已有存档迁移不重置进度。
- 新增 `diary.js` 与第九个面板：每天配置时区21:00根据实际世界经历写日记，历史与通知分开保存、离线逐日补写、日期去重。
- 自动测试扩充至101项；独立假时钟浏览器验收9个页面和配种、代宰、雇佣、21:00写作以及模式选择。
