# 田园烟火 · 功能点汇总介绍

适用版本：1.1.1。运行于 Coopanion World API 6，中文界面，默认使用 Asia/Shanghai 时区。

## 一句话介绍

给桌宠一座会随真实时间运转的田园小院：从开荒种田、养殖繁育，到下厨做饭、仓储保鲜、负重赶集，再用每晚九点的一篇日记留下当天的生活。

## 核心玩法

### 1. 从荒地开始的种植生活

- 初始六块荒田，需要先开垦再播种；内置30类作物，涵盖水稻、小麦、玉米、豆类、根茎、叶菜和瓜果。
- 支持浇水、除草、施肥、防虫、排水、设置稻草人、清田和收获。
- 作物经历萌芽、幼苗、生长、开花结实和成熟等阶段；水分、杂草、虫害和健康影响长势与收成。
- 默认理想生长周期约28–120个真实小时，可在配置中调整生长倍率。

### 2. 有好有坏的天气与农事事件

- 晴天、及时雨、和煦日照、蜜蜂授粉能带来不同的田园体验。
- 热浪干旱、暴雨洪涝、蝗灾、倒春寒和冰雹会影响田地，需要及时照料。
- 天气随真实时间推进并持久保存，刷新页面不会重新抽取。

### 3. 养殖、繁育与动物照料

- 关闭宝宝模式后，可饲养鸡、鸭、鹅、牛、羊、猪和鱼。
- 动物有年龄、性别、健康、饱食和体力；支持补饲、治疗、配种、妊娠或孵化、产仔和自然寿终。
- 同种、成年、健康的公母动物才能配种；母牛生产后才泌乳，禽类可产蛋，羊可剪毛。
- 兽药按疗程与给药冷却工作，治疗恢复与病损同时结算；病死动物没有可食用产物，可做无害化处理。
- 设有禽舍、畜棚和鱼塘容量限制，动物生理年龄默认每个真实日推进30天。

### 4. 宝宝模式

- 默认开启，首次打开总览提供选择，之后可在 World 配置随时切换。
- 开启时禁用养殖和屠宰操作，冻结已有动物的生命、妊娠及治疗进度，已有动物保留。
- 集市照常出售活禽运输箱与肉类；关闭后开放完整养殖玩法，一次性发放初始养殖礼包。

### 5. 从收成到餐桌的厨房

- 内置100道菜谱，支持蒸、炒、煮、炸、烤和凉拌。
- 烹饪需要对应厨具、食材、调料、水和燃料；厨具会被任务占用，按真实时间等待出锅。
- 可以用手摇磨把稻谷加工成米、把小麦加工成面粉。
- 食材的新鲜程度会传递给成品，烹饪不能把陈旧食材重新变新鲜。

### 6. 有容量限制的仓储与批次保鲜

- 食品柜20kg、粮仓80kg、地窖40kg、冰箱25kg、工具棚60kg、厨余垃圾桶10kg、门廊收货箱350kg；背包健康时基准上限12kg。
- 不同容器适合不同物品：干粮入粮仓、根茎入地窖、肉奶和熟食入冰箱，保鲜延缓效果各不相同。
- 食品按批次累计老化；转仓、交易、加工和托运保留已消耗的保鲜时间。
- 新鲜度下降会降低饱腹收益；临期食品可能降低愉悦和健康，完全过期后禁止食用。
- 过期食品可放入厨余桶处理，累计厨余还可以堆肥。门廊收货箱只解决临时接货容量，不提供冷藏。

### 7. 相互影响的生活数值

- 饱腹、愉悦、健康、体力、水分、清洁、社交和保暖，共八项状态。
- 支持吃饭、喝水、洗漱、休息、玩耍和服药；饮食质量、疲劳、缺水等会相互影响。
- 丰收、天气、动物和生活事件会留下实际经历；雨中玩耍可能感冒，健康下降也会影响负重。

### 8. 按真实时间开放的集市

- 每天06:30–11:30、14:00–17:00营业，按配置时区判断。
- 物品和金币都计重量；重量不足1kg显示g，达到1kg显示kg，金币每枚0.5g。
- 可选择携带的货物、金币和随行动物；负重影响路程，到达时可能已经闭市。
- 支持买卖和金币补差价的物物交换；已生成物品具有可查询的价格与重量。

### 9. 固定作坊、流动商人与公告订货

- 七类固定作坊：油坊、盐坊、茶坊、器具坊、作物坊、食材坊和畜牧坊。
- 流动商人每日随机刷新有限库存，马车默认承载上限180kg。
- 支付公告费用后，可登记本世界已有的物品需求，安排次日优先到货。
- 若需求超过商人载重，优先让更多种类各到一件，再分配剩余容量；实物抵费超额不找零。

### 10. 驮运、代宰与次日送货

- 健康成年牛羊可随行驮运，年龄、健康、饱食和体力共同影响承载与速度。
- 在家可使用屠宰卫生套件，或让食材坊有偿代宰；按物种产出肉、内脏、脂肪、皮、骨、羽毛或羊毛。
- 屠宰后立即扣除该动物的驮力，带不走的产物留坊待运。
- 可雇佣小厮托运留坊货物或背包货物，单次最多100kg，次日当地08:00自动送到家，桌宠无需在家。
- 代宰与跑腿均支持金币或足值实物支付；冰箱放不下的送货进入门廊，需及时整理保鲜。

### 11. 主人可扩展的菜谱与物品

- 提供专用页面填写菜谱食材、佐料、烹饪方式、耗时、用水、产量、价格、保鲜、饱腹、愉悦和步骤。
- 主人新增菜谱不会直接教给桌宠，而是从次日起进入商人货池，买到后才解锁。
- 物品编辑器支持重量、价格、分类、食用属性、保鲜、标签、所属作坊，以及种子的生长模型。
- 校验重复物品、属性边界、作坊相关性和食材合理性；固定作坊新货次日上架，流动商人新货次日起有机会随机出现。

### 12. 每晚九点的小院日记

- 每天配置时区21:00，根据本世界当天实际发生的事写一篇第一人称日记。
- 可记录天气、农事、收获、烹饪、照料、动物和赶集经历，支持历史回看。
- 21:00之后的经历进入下一篇；离线后启动会逐日补写，同一日期不会重复。
- 日记使用世界事件模板编写，不额外调用模型，不读取其他聊天或电脑文件。

### 13. 真实时间与持久存档

- 世界按真实时间运转，不需要一直打开页面；下次启动补算作物、保鲜、动物、行程、订单和日记。
- 主人操作与桌宠工具共用规则，检查所在地、时间、材料、容量、保鲜和工具条件。
- 采用串行操作和原子存档，支持旧存档增量迁移，升级保留已有田地、库存、菜谱与配置。

## 九个管理页面

田园总览、田地与天气、动物与养殖、厨房与菜谱、仓储与保鲜、赶集与公告、小院日记、添加菜谱、添加物品。

## 适合直接分享的介绍

**田园烟火**是一款为 Coopanion 桌宠打造的田园生活 World 扩展。在六块荒田里种下30类作物，照料鸡鸭牛羊，把收成做成100道家常菜，再带上货物与随行家畜去赶集。天气、保鲜、负重和八项生活状态随真实时间变化；作坊、流动商人、公告订货和次日跑腿送货串起小院的日常。主人还能通过页面添加新物品与菜谱，让桌宠在集市中发现新的生活可能。默认宝宝模式，每晚九点写下小院日记，把一天的烟火气留成回忆。

具体数值与游戏规则见[设计说明](DESIGN.md)，全量目录见[目录参考](CATALOG.md)。价格、保鲜、疾病和生理速度均为游戏模拟参数。
